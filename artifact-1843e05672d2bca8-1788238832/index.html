WHY NOW

不是聊天截图。
是能交互的结果。

传统需求从文档到原型，需要产品、数据和前端多轮翻译。Meta-Eve 把第一轮验证压缩成一个闭环。

INPUT

吃懂现有数据

Markdown、SQL、JSON、YAML、CSV、TXT 都能进入上下文。表、字段、关系和业务口径一起被读取。

BUILD

围绕业务任务生成

用户说清楚角色、目标和关键操作。系统生成筛选、指标、列表和详情，而不是只输出一段代码。

LEARN

每次迭代都有历史

每个版本保存为 App，同一思路归入 Session。团队可以重开、比较、继续生成，不丢上下文。

让业务专家先拿到可玩的答案，再决定值得构建什么。
